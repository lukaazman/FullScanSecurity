# FullScanSecurity

FullScanSecurity is a free Android security scanner that reviews app access, device settings, and other security signals without requiring root access.

## Download Android App

[![Download Android App](https://img.shields.io/badge/Download-Android%20App-3DDC84?logo=android&logoColor=white)](https://github.com/lukaazman/FullScanSecurity/releases/latest/download/FullScanSecurity.apk)

Download the latest APK using the button above.

## Install

1. Open the downloaded `FullScanSecurity.apk`.
2. If Android asks, allow your browser or file manager to install unknown apps.
3. Complete the installation and open FullScanSecurity.

The app is free, ad-free, and does not require root access.
